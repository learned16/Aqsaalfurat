# بوت أقصى الفرات على تلغرام

بوت مجاني يشتغل على حساب Google مال الشركة (Google Apps Script). يستلم طلبات المناقصات والاعتذارات والوصولات من الموظفين، ويحفظها بالدرايف، ويرجّع الملفات الجاهزة، ويطبع بعد موافقة المدير.

## شلون يشتغل

1. الموظف يفتح البوت ويدوس **📑 إنشاء مناقصة**. البوت يسأل خطوة بخطوة: الشركة، الرقم، الجهة، الغلق، السعر، المرفقات، الملاحظات.
2. يدوس **أرسل**. المرفقات تنحفظ بالدرايف بمجلد `09_طلبات_البوت/الطلبات/<رقم الطلب>/مرفقات`، والطلب ينضاف لجدول «طابور بوت أقصى الفرات».
3. Claude يفحص الطابور كل ساعة، ويبني الحزمة، ويرفع النتائج لمجلد `النتائج` عن طريق `bridge.py`.
4. البوت يرسل الملفات لمقدم الطلب، وللمدير ويه زرين: **✅ اطبعه** و**↩️ رجّعه للتعديل**.
5. المدير يدوس اطبعه، فينرسل الـ PDF لإيميل طابعة Epson Connect ويطلع مطبوع.

**وصل:** الموظف يصوّر الوصل ويكتب المبلغ والوصف، فينحفظ بمجلد `الوصولات/<الشهر>` وينسجل بورقة «الوصولات».

## التنصيب (مرة وحدة، حوالي 15 دقيقة)

### 1. سوي البوت
1. بتلغرام دوّر على **@BotFather** واكتب `/newbot`.
2. سمّيه (مثلاً: بوت أقصى الفرات) واختار اسم مستخدم ينتهي بـ `bot`.
3. ينطيك **رمز** شكله `123456:ABC...`. احتفظ بيه ولا تنشره.

### 2. انسخ الكود لـ Apps Script
1. افتح [script.google.com](https://script.google.com) **من حساب الشركة** companyaqsaalfurat@gmail.com، ودوس **New project**، وسمّيه «بوت أقصى الفرات».
2. لكل ملف بمجلد `apps-script/` هنا: سوّي ملف بنفس الاسم وانسخ المحتوى (Config، Telegram، Storage، Bot، Api، Setup).
3. من **Project Settings** فعّل «Show appsscript.json»، وانسخ محتوى `appsscript.json`.

### 3. حط الإعدادات
من **Project Settings ← Script Properties** ضيف:

| الاسم | القيمة |
|---|---|
| `TELEGRAM_TOKEN` | رمز البوت من الخطوة 1 |
| `MANAGER_ID` | معرّف تلغرام المدير (يطلع من `/myid` بالبوت) |
| `ALLOWED_IDS` | معرّفات الموظفين مفصولة بفارزة |
| `PRINTER_EMAIL` | إيميل طابعة Epson Connect (اختياري لحد ما تتسجل الطابعة) |

### 4. شغّل التنصيب
1. بالمحرر اختار الدالة `setup` ودوس **Run**. أول مرة يطلب صلاحيات: وافق عليها.
2. دوس **Deploy ← New deployment ← Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
3. انسخ رابط الـ Web app (ينتهي بـ `/exec`).
4. ضيفه بـ Script Properties باسم `WEBAPP_URL`.
5. شغّل `setWebhook`، وبعدها `showConfig`.
6. من **Triggers** ضيف مشغّل يومي للدالة `cleanTemp`.

### 5. اربط Claude
`showConfig` يطبع `BOT_URL` و`BOT_KEY`. حطهم كمتغيرات سرية بإعدادات بيئة Claude (مو بالمحادثة). وبإعدادات الشبكة اسمح بـ `script.google.com` و`script.googleusercontent.com`.

### 6. جرّب
1. ابعث `/myid` للبوت من موبايلك وموبايل المدير، وحط المعرّفات بـ `ALLOWED_IDS` و`MANAGER_ID`.
2. ابعث `/start` وجرّب طلب اعتذار.

## أوامر Claude (`bridge.py`)

```bash
export BOT_URL=... BOT_KEY=...
python3 bridge.py list                         # الطلبات الجديدة
python3 bridge.py files R261008-001            # مرفقات الطلب (ids بالدرايف)
python3 bridge.py update R261008-001 "قيد العمل" --notify
python3 bridge.py upload R261008-001 out/*.pdf out/*.docx
python3 bridge.py deliver R261008-001 --manager --msg "الحزمة جاهزة، باقي التوقيع والختم"
python3 bridge.py notify manager "نشرة المناقصات: ..."
```

## الأمان

- البوت يرد بس على المعرّفات بـ `ALLOWED_IDS` و`MANAGER_ID`.
- زر الطباعة يشتغل بس للمدير.
- تلغرام يوصل للسكربت برابط بيه `TG_SECRET`، وClaude يوصل بـ `API_KEY`. الثنين يتولّدون وحدهم بـ `setup()`.
- ما ينحذف أي ملف أصلي. بس ملفات «مؤقت» من الطلبات الملغية بعد يومين.

## الحدود

- تلغرام ما ينزّل ملفات أكبر من 20 ميغا. الملف الأكبر يترفع للدرايف يدوياً.
- Epson Email Print: لحد 10 مرفقات و20 ميغا بالمجموع، وPDF بس.
- Claude يفحص الطابور كل ساعة، فالطلب ما يكون فوري.
